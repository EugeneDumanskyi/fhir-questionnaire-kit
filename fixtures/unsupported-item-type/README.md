# `unsupported-item-type`

**Behaviour:** Item types outside the supported set (AC-01.3.1, AC-01.3.2, INV-D-03).

`strict` rejects, listing each item; `lenient` keeps a placeholder that is excluded from answers.

**Authored** for the kit, not copied from the HL7 specification. `scenario.json` is read by `packages/core/test/conformance/fixtures.test.ts` (shape: `fixtures/README.md`).
