# `repeat-instances`

**Behaviour:** Repeating groups: per-instance conditions, ordinals never reused, Add refused at maxOccurs, Remove never refused on cardinality (AC-03.2.1–5, INV-S-08, INV-S-20–24, M2 AC-7).

Paths carry ordinals, which are identity, not position (T11).
